Student Grade Calculator

About the Project

This is a simple Student Grade Calculator developed using C programming. It calculates the total marks, percentage, and grade of a student based on marks obtained in five subjects.

Features

- Takes student name as input.
- Accepts marks in five subjects.
- Calculates total marks out of 500.
- Calculates percentage.
- Assigns grades based on percentage.

Grade Criteria

Percentage| Grade
90% and above| A
75% - 89%| B
60% - 74%| C
40% - 59%| D
Below 40%| F

Technologies Used

- C Programming
- GCC Compiler
- VS Code

Concepts Used

- Variables and Data Types
- Arrays
- For Loop
- If-Else Statements
- Input and Output
- Arithmetic Operations

How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the program:

gcc student_grade_calculator.c -o student_grade_calculator

5. Run the program:

./student_grade_calculator
