Number Guessing Game 🎮

About the Project

A simple Number Guessing Game developed using C programming.

The computer generates a random number between 1 and 100, and the user tries to guess it.

Features

- Random number generation
- Too High / Too Low hints
- Number validation
- Attempts counter
- Repeated guessing using do-while loop

Concepts Used

- C basics
- If-else statements
- Do-while loop
- Random number generation
- Variables and user input

How to Compile

gcc number_guessing.c -o number_guessing

How to Run

./number_guessing

Language

C Programming
